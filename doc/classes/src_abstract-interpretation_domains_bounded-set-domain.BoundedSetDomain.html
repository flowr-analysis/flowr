    Class BoundedSetDomain<T, Value>

    The bounded set abstract domain as sets of possible values bounded by a limit indicating the maximum number of inferred values. The Bottom element is defined as the empty set and the Top element is defined as Top symbol.

    Type Parameters

    • T

      Type of the values in the abstract domain

    • Value extends BoundedSetLift<T> = BoundedSetLift<T>

      Type of the constraint in the abstract domain (Top, Bottom, or an actual value)
