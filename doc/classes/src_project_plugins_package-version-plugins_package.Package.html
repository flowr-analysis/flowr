    Class Package

    A package as the sources describe it, accumulated with addInfo/mergeInPlace: only those may change it, everything else reads. Its three version views run from the rawest to the most concrete:

    • versionConstraints: what each source declared, unmerged.
    • derivedRange: their intersection, whether or not a version can satisfy it (see hasSatisfiableVersion, and inferredRange on the dependencies context for the range that is only handed out once it is).
    • resolvedVersion: the one concrete version the exports were read from.
