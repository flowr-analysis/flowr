    Class OnDemandRecoverer

    Recovers packages no signature database knows from their sources: asks each OnDemandSource in turn for archives, reads DESCRIPTION, NAMESPACE, and R/ from the first one that holds the package, and caches the result (or that no source had it) as one JSON file per package, so later analyses need no network.
