    Class TaintAnalysisDefinition<Name, Domain, Config>

    Fluent builder class for defining new taint analyses. Use TaintAnalysisDefinition.create to obtain an instance; The methods TaintAnalysis.from, TaintAnalysis.through, TaintAnalysis.to, and TaintAnalysis.report have to be called in order.

      ): CompositeTaintAnalysisDefinition<Name>

      Composes at least two taint analysis definitions into a single composite taint analysis. The component analyses are evaluated simultaneously during a single control-flow traversal and their taints are combined into a product of the lattice values per each CFG node (see TaintInterpreter).
