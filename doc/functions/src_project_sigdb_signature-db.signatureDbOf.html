    Function signatureDbOf

    • signatureDbOf(deps: ReadOnlyFlowrAnalyzerDependenciesContext): SignatureDb

      Builds the SignatureDb that ReadOnlyFlowrAnalyzerDependenciesContext.signatures hands out.

      Call this only where you hold a dependencies context but no analyzer, e.g. inside a plugin or a query executor. Everywhere else go through analyzer.inspectContext().deps.signatures(). It exists so the version resolution lives in one place instead of every caller pairing a PackageSignatureSource with a getDependency(...)?.resolvedVersion of its own.

      The result keeps no state, so it stays correct when a database is mounted or a version is re-resolved later.

      • deps: ReadOnlyFlowrAnalyzerDependenciesContext
