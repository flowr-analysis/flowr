    Interface BranchPaths

    Works out, for every node of every function body, the branches taken on the way there from the start of the body, see BranchPathDomain. Each body is interpreted on its own, whether or not anything calls it, without stepping into what it calls, and the state is kept per function definition (the key is its id).
