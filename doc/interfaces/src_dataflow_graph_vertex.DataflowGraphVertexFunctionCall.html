    Interface DataflowGraphVertexFunctionCall

    Arguments required to construct a vertex which represents the call to a function in the DataflowGraph|dataflow graph. This describes all kinds of function calls, including calls to built-ins and control-flow structures such as if or for (they are treated as function calls in R).

    See

    FunctionCallVertex.is - to check if a vertex is a function call vertex
