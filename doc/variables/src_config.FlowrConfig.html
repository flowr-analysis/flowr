    • forKind: function
      • forKind(this: void, config: FlowrConfig, kind: ProjectKind): FlowrConfig

        Resolves the configuration for the given ProjectKind by applying the matching FlowrConfig.specializeConfig entry to every key it names. What you configured wins over the entry, which in turn wins over flowR's default; a value that differs from the default counts as configured. Returns config itself if the kind has no entry, so callers can use this freely.
