    The calls and the closures of a program between each other: who calls a function, what a call binds to its formals, and the arguments a call stands for once the parameters it hands on (f <- function(...) g(...)) are replaced by what the calls of f give. Everything interprocedural asks these instead of looking at one function alone.

      • contexts<Info>(

            graph: DataflowGraph,
            sites?: readonly CallSite<Info>[],
            ctx?: ReadOnlyFlowrAnalyzerContext,

        The argument lists the arguments args of a call stand for across the calls that reach it, one per chain of calls: each argument handing on a parameter of a function (..., or x of function(x)) is replaced by what the call in sites running that function gives, or else by what each known call of it gives (see CallSites.callersOf). An argument no known call settles stays as written, so what it stands for stays open; ctx tells whether other code may call the functions, see CallSites.callersOf.
