    Records the control flow of a program in the DataflowGraph while the dataflow analysis walks it. The ControlFlowGraph is a view on what is recorded here.

    The control flow is modeled in post-order: everything a construct is made of runs before the construct itself, so its own vertex is where its parts join again and where it is left.

    • promise: function
      • promise(
            this: void,
            graph: DataflowGraph,
            promise: DataflowCfgInformation | undefined,
            forcing: Ternary,
            holder: NodeId,
        ): ExitPoint[]

        The jumps within a promise, an argument or default R evaluates only if holder forces it. A jump

        • never runs if the promise is Ternary#Never|never forced, so control resumes at holder,
        • leaves whenever reached if it is Ternary#Always|always forced,
        • otherwise stays an exit under a byPromise dependency on holder, and control may resume at holder as well, until FunctionSemantics.settleJumpsInPromises settles it.
