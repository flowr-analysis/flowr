    • dropResolvedMask: function
      • dropResolvedMask(
            this: void,
            graph: DataflowGraph,
            id: NodeId,
            name: Identifier,
        ): MaskingCall | undefined

        Drops the mask mark from names the caller binds to a value: while filter(d, k) is processed k has no read yet. A name bound to a function keeps its mark, as filter(d, id > 2) next to id <- function(...) still means the column. Hands back the masking call and the names it just unmarked, undefined when name does not mask at all, so linkMasksToData need not ask a second time.

    • linkMasksToData: function
      • linkMasksToData(
            this: void,
            graph: DataflowGraph,
            calls: readonly MaskingCall[],
        ): void

        Links every name the data masks of calls supply to the data it comes from: id in filter(df, id > 2) is a column of df, so it reads df. Run once every mark has settled, as adding the read makes suppliedByMask false for the name; a call whose first argument is masked too has no data to link against.
