        The routine a foreign function call names, the way R finds it: an R variable is the one useDynLib binds (the database's SigNativeRoutineInfo.rNames, else the package's useDynLib directives, if given); a string is first a registered name of the call's interface, then any registered name, then a linker symbol ("foo" also finds the Fortran symbol foo_). undefined when nothing matches.
