            "from-query",
            [],
            ParentInformation,
            FlowrSearchElements<ParentInformation, FlowrSearchElement<(...)>[]>,
        >

        Initializes a new search query based on the results of the given JSON query or queries. Internally, the SupportedQuery#flattenInvolvedNodes function is used to flatten the resulting nodes of the query. Please note that, due to the fact that not every query involves dataflow nodes, the search may not contain any elements at all for certain queries.
