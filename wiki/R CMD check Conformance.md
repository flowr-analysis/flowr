They run by default only for packages (config option `linter.disabledTags`), see the [linter](https://github.com/flowr-analysis/flowr/wiki/Linter) for all rules.
Below are all steps of `R CMD check`, numbered by us (R itself prints them as `* checking ...`), each linked to its code in [R's `check.R`](https://github.com/wch/r-source/blob/tags/R-4-6-1/src/library/tools/R/check.R) and its section in R Packages.
